Commands

Request About Info

Get the info of the about dialog including build date and version nr. Causes "About Dialog Content" to be sent.
Position Description
0:1 Command Nr: 0
2:3 Command Length, 4 by default
Example
0x0
0x0
0x4
0x0

Get All Programs

Returns the name and properties of all fx programs available on the device. Causes "FX Programs Description" to be sent.
Position Description
0:1 Command Nr: 1
2:3 Command Length, 4 by default
Example
0x1
0x0
0x4
0x0

Get Parameter Names

Returns all parameter Names of a given program. Causes "FX Parameter Names" to be sent.
Position Description
0:1 Command Nr: 2
2:3 Command Length, 5 by default
4 Index of the Program for which the parameter should be returned
Example
0x2
0x0
0x5
0x0
0x3

FX Programs Description

Contains the names and properties of all Fx Programs available on the device.
Position Description
0:1 Message Nr: 1
2 Total number of Fx Programs.
3 Properties of the first FX Program
Bit 7: 1 if the effect is freezable, 0 otherwise
Bit 6:0 the number of parameters of the fx program
4:N the Name of the Program as a zero-terminated string.
N+1:M Properties and Names of the remaining FX Programs.
Example
0x1
0x0
0x2
0x84
'D'
'e'
'l'
'a'
'y'
0x0
0x01
'B'
'o'
'o'
's'
't'
0x0

FX Parameter Names

Position Description
0:1 Message Nr: 2
2:N First Parameter Name as a zero-terminated string.
N+1:M second Parameter Name as a zero-terminated string.
... ...
Y+1:Z last Parameter Name as a zero-terminated string.
Example

0x0

'a'
