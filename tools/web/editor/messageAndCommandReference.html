Sets Input and Master Volume State

Sets the input states and Master Volume level.
Position Description
0:1 Command Nr: 4
2:3 Command Length, 6 by default
4 Bit 0: HiZ Input state, 1 for "on", 0 for "off"
Bit 1: Mic Input state, 1 for "on", 0 for "off"
Bits 2:7 ignored
5 The Master Volume level, 255 for max, 0 for min.

Set Parameter

Set a parameter nr N of the program at index A (0-2) to a Value V. Causes a "Parameter Value" message to be returned which contains the textual description of the parameter value.
Position Description
0:1 Command Nr: 7
2:3 Command Length, 8 by default
4 program index (0-2)
5 parameter index within the program
6:7 the value of the parameter (0-4095)
Example
Setting the fourth parameter (parameter index 3) of effect B (program index 1) to the value 1023

Set FX Program

Set the FX Program at the given position.
Position Description
0:1 Command Nr: 10
2:3 Command Length, 6 by default
4 Position within the preset (0-2)
5 FX Program nr 0 up to the number of different fx programs, 0xFF/255: bypass/no program

Switch On/Off FX Program

Switches the FX Program on or off.
Position Description
0:1 Command Nr: 11
2:3 Command Length, 6 by default
4 Position within the preset (0-2)
5 0: Switch Off, 1: Switch On. Note: this command si ignored when no program is loaded at the given position

Preset

Contains the Information about a preset
Position Description
0:1 Message Nr: 6
2:3 Message Size
4 the Bank Number
5 bits 0:1: the Preset Number on the range 0-2 bits 2:7: The Effect Routing
0:
1:
2:
3:
4:
6 Bit 0:1: state of effect A, 0: off, 1: on, 2: frozen Bit 2:3: state of effect B Bit 4:5: state of effect C
7:7+S The name of the Preset as a zero-terminated string
N Program Nr for Program A, 255 means none
N+1:N+NO All O parameter values of Program A as 2byte little endian, followed by the display Value as a zero-terminated string
M Program Nr for Program B, 255 means none
M+1:M+1+NQ All Q parameter values of Program B as 2byte little endian, followed by the display Value as a zero-terminated string
P Program Nr for Program C, 255 means none
P+1:P+1+NW All W parameter values of Program C as 2byte little endian, followed by the display Value as a zero-terminated string
Example
Preset at Bank Nr 4, at position 1, serial routing, named "Demo". In Slot A Program Nr 3 is loaded having two parameters which have the values 0x1AC, display Value "Muh" and 0x1DC, display value "Maeh". On Slot B and C no programs are loaded
